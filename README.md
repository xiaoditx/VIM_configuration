# Vim配置工具（GUI版本）

这是一个基于C++的Vim配置软件，提供了可视化的配置界面，让用户可以方便地配置Vim编辑器的各项功能。

## 功能特点

1. **类手机设置风格的可视化配置界面**
   - 通过点击按钮切换功能开关状态
   - 每个配置项配有问号标记，点击可查看详细用法说明

2. **配置项管理**
   - 支持单选框/开关按钮（用于描述开关状态的配置项）
   - 自动加载和保存Vim配置文件
   - 实时显示和编辑配置项

3. **配置文件处理**
   - 程序启动时自动读取系统vimrc配置文件
   - 用户完成配置后，点击"保存配置"按钮将格式化后的配置写入目标文件

## 技术栈

- **主编程语言**: C++
- **GUI实现**: Windows API（原生，无第三方库）
- **编译工具**: g++/MinGW
- **构建系统**: Makefile

## 编译和运行

### 前提条件

确保您的系统上已安装以下工具：
- MinGW (包含g++编译器)
- make工具

### 编译步骤

1. 打开命令提示符（CMD）或PowerShell
2. 导航到项目目录
3. 执行以下命令：
   
   ```bash
   make
   ```

### 运行程序

编译成功后，可以通过以下方式运行程序：

1. 直接双击生成的`vim_config_tool.exe`文件
2. 或在命令行中执行：
   
   ```bash
   make run
   ```

### 清理生成文件

如果需要清理编译生成的文件，可以执行：

```bash
make clean
```

```

├── README.md        # 项目说明文档

```

## 使用说明

1. 启动程序后，将自动加载系统中的Vim配置文件
2. 在配置界面中，您可以通过勾选/取消勾选来启用/禁用各项配置
3. 点击每个配置项旁边的"?"按钮，可以查看该项的详细说明
4. 完成配置后，点击"保存配置"按钮将更改保存到配置文件中
5. 点击"取消"按钮退出程序，不保存任何更改

## 注意事项

- 本程序使用Windows API开发，目前仅支持Windows操作系统
- 程序不依赖任何第三方库，可以通过原生编译器直接编译运行
- 配置文件默认保存在系统用户目录下的`_vimrc`文件中
